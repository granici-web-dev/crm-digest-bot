# Метрики владельца: что есть, чего нет

Источник: ручной файл владельца «MARKETING & VÂNZARI SofaBelle 2025.xlsx» (разобран 29.09.2026 скриптом, только структура и агрегаты). В файле: помесячные листы июнь 2025 — август 2026 (по дням, с колонками Total / Prognoza / Plan / Abatere), лист Dashboard (апрель 2024 — июль 2025 помесячно), лист Showrooms, лист Contracte — реестр договоров с ПД клиентов (имя, телефон, адрес). Файл в репозиторий не класть; при необходимости только в `docs/reference/`.

## Формулы владельца (проверены на листе IULIE 2026)

| Метрика | Формула в файле | Пример июль 2026 |
|---|---|---|
| Leads Total | Site (Mail/FB/IG + Telefon + WhatsApp) + Designer/Colaboratori + Alte; **Showroom в лиды не входит** | 176 |
| Conversie Vizita | Vizita / Leads Total (может быть > 100 %) | 188 / 176 = 107 % |
| Conversie Oferta (V/O) | Oferta / Vizita | 155 / 188 = 82 % |
| Conversie Oferta (L/O) | Oferta / Leads Total | 155 / 176 = 88 % |
| Conversie Contract (O/C) | Contract / Oferta | 43 / 155 = 28 % |
| Lead to Contract Rate | Contract / Leads Total | 43 / 176 = 24 % |
| Cost per Lead | Buget Digital Total / Leads Total Site | 265 lei |
| CPL all | Buget / Leads Total | 244 lei |
| Conversie site | Leads Total Site / Trafic (sesiuni) | 1,1 % |
| Cost Acquisition Contract (CAC) | Buget / Contract | 998 lei |
| Cec mediu | Valoare Contract / Contract | 14 509 lei |
| ROAS | Valoare Contract / Buget | 14,5 |
| Plan / Prognoza / Abatere | план месяца (1 000 000 lei), прогноз по темпу, отклонение | план 1 000 000 |
| Total € | Valoare Contract в евро | — |

**Расхождение определений.** Наш LEADS (бриф, KPI) включает лиды с источником Showroom; у владельца Leads Total их не включает, визиты идут отдельной строкой. Поэтому L/O и O/C владельца не равны нашим L2O и O2C. Если показываем владельцу его таблицу — считать по его формулам отдельными функциями в `metrics/`, а не подменять KPI брифа.

## Что есть, чего нет

Источники: A — mefi leads, I — mefi clients, D — рекламные кабинеты, E — GA4, R — реестр договоров (лист Contracte), B — API mefi (оферты, договоры, оплаты), F — история из этого файла.

| Метрика | Источник | Статус |
|---|---|---|
| Лиды по каналам (Mail/FB/IG, Telefon, WhatsApp, Site, Designer, Alte) | A | ✅ d1, w1, m7 |
| Vizita, Oferta, Contract Cantitate | A, I | ✅ d1, w2, w3, m2 |
| V/O, L/O, O/C, Lead→Contract | A, I | 🟡 есть по формулам брифа; по формулам владельца — нет |
| Разбивка по шоурумам | A | ✅ |
| Бюджет Meta / Google / TikTok, CPL, CPL all, CAC | D | ❌ ждёт доступов (М1) |
| Трафик, Conversie site | E | ❌ ждёт GA4 (М1) |
| Valoare Contract, Cec mediu, ROAS, Total € | R или B | ❌ реестр есть уже сейчас (В6), API mefi — позже |
| Încasări (аванс, остаток) | R или B | ❌ в реестре есть «Avans» и «Rest de plată» |
| План / прогноз / отклонение | R + конфиг плана | ❌ план — вопрос В7 |
| Выручка по шоурумам | R (+ связь с шоурумом) | ❌ |
| Топ продуктов и тканей (m16 без маржи) | R | ❌ |
| YoY, сезонность (y1, y2) | F + R | ❌ разовый импорт помесячных агрегатов 2024–2026 |

Реестр ведётся по сей день: по листу Contracte в 2026 году 23–41 договор в месяц (июль 2026 — 41 на 597 994 lei; в mefi Clienți за июль — 40). Это самый быстрый путь к деньгам, без ожидания API mefi.

## Кому что (предложение)

- **Ежедневно** (группа): как сейчас — лиды по каналам, визиты, оферты, договоры (d1). Плюс, когда будут R и D: сумма договоров дня и месяц нарастающим итогом против плана; расход рекламы вчера.
- **Еженедельно**: воронка и источники (есть); плюс CPL по каналам (D), сессии и конверсия сайта (E), сумма договоров недели и ROAS недели (R + D).
- **Ежемесячно — главный отчёт владельцу**: его таблица «Marketing & Vânzări» по его формулам: бюджеты по платформам, трафик, лиды по каналам, CPL, конверсии V/O, L/O, O/C, договоры, CAC, сумма договоров, средний чек, план / прогноз / отклонение, ROAS, итог в €, выручка по шоурумам. Плюс то, что уже есть: тренд 6 месяцев, KPI консультантов.
- **Ежегодно**: YoY по месяцам (лиды, договоры, сумма, бюджет, ROAS), сезонность, лучшие месяцы, топ продуктов и тканей.

## Возможность на потом

В реестре есть телефон клиента. Хешем тем же способом, что `contact_keys.py` (в памяти, без хранения телефона), договор можно связать с лидом mefi и получить ROAS и CAC по источнику лида. Только после отдельного ADR о ПД.
