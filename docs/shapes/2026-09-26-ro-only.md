# Shape: отчёты только на румынском (26.09.2026)

## Goal
Отчёты в группу рендерятся только по-румынски, языковой параметр исчезает из кода, конфига и базы. Служебный бот остаётся на русском.

## Approach
Ось языка убирается целиком, а не прячется: `render(template_name, **values)` берёт `templates/<name>.j2`, `chart_labels()` читает `templates/charts.yaml`, `ReportContext` без поля `language`. Ветки `label_ro if ... else label_ru` в модулях исчезают вместе с полями `label_ru`, `below_label_ru` в конфиге; `label_ro` → `label`, `below_label_ro` → `below_label`. Раннер не читает `settings`, `seed_defaults` не пишет `report_language`; строка в базе остаётся мёртвой, миграции нет. Syrupy-снапшоты перегенерируются, diff `.ambr` содержит только удаление `-ru`-блоков и переименование ключей `[x-ro]` → `[x]`, содержимое RO не меняется.

## Schema / API changes
Нет. Таблица `settings` остаётся, ключ `report_language` больше не пишется и не читается.

## Test plan
- Syrupy: каждый реализованный модуль через существующие рендер-тесты без параметра языка; `git diff` `.ambr` подтверждает, что RO-текст не изменился.
- `test_templates_contain_no_cyrillic`: все `templates/*.j2` и `charts.yaml`, кириллица ищется после вырезания `{# ... #}` и YAML-строк, начинающихся с `#` (WHY-комментарии по CLAUDE.md русские).
- Интеграция: `test_legacy_report_language_row_is_ignored` (строка `"ru"` в `settings`, текст в группе румынский), `test_seed_defaults_keeps_existing_values` проверяет, что `settings` пуст после засева.
- `pytest -q`, ruff, mypy strict.

## Tradeoffs / alternatives considered
- Оставить `label_ru` в конфиге «на будущее»: обязательное поле без читателя это полузаконченная ветка (PRINCIPLES «Дисциплина»).
- Оставить `ReportLanguage = Literal["ro"]` с дефолтом: настраиваемость с одним значением.
- Отдельный ADR: ADR у проекта для формул KPI; продуктовое решение фиксируется пометкой в brief и разделом CLAUDE.md.
- Проверять кириллицу по снапшотам: снапшот покрывает только ветки тестовых данных, файл покрывает всё.
