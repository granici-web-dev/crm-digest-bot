# Ручной понедельничный отчёт: образцы за июль 2026

Источник: три файла `Sofabelle_leaduri_*_FARA_Showroom.xlsx` (Downloads, 20.07.2026), собранные вручную до бота. Лист с лидами не перенесён (там имена клиентов), здесь только сводные листы. Это формат и правило счёта для модуля `w1`.

## Правило рабочего окна (дословно из файлов)

> Рабочие часы 10:00–19:00. Лиды в этом окне засчитаны в текущий день; лиды вне окна перенесены на следующий календарный день (продавцы обрабатывают их только в рабочее время).

Проверено по строкам листа `Date`: лид 01-07 00:32 → рабочий день 02-07; лид 13-07 **09:51** → 14-07 (до 10:00 тоже переносится на следующий день, не на текущий); лид 13-07 10:18 → 13-07. Источник `Showroom` исключён из счёта целиком («FARA Showroom»). Лид без даты показан отдельной строкой «+ N lead fără dată». Лиды без шоурума или без источника идут в колонки «(fără showroom)» и «(fără sursă)».
