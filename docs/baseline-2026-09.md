## Правило сравнения «после»

1. Та же команда, тот же снапшот-тип: `baseline --date` только на последний день месяца; запас — на дату, поток — за календарный месяц (окна 19:00), консультанты — с 01.06 и отдельно за месяц. На другую дату команда печатает предупреждение: строки `cur` тогда за неполный месяц. База 29.09.2026 снята до правила (снапшота 30.09 на момент фиксации не было), её `cur` — сентябрь без последнего дня.
2. Первое сравнение — 31.10.2026 (месяц после базы), затем ежемесячно; таблица «база → сейчас → цель» уходит владельцу в месячной сводке (`success-criteria.md`, этап 4).
3. Сезонность: рядом с «до/после» показывать тот же месяц прошлого года из файла владельца (E1, E2, D4, D5), иначе осенний рост припишут агентам.
4. Метрика засчитывается агенту, только если агент действовал в этом месяце (журнал действий агента) и метрика изменилась в его области; остальное — «изменилось без нас».
5. Цели выше — предложение Davoq; согласовать с владельцем при первом сравнении, дальше не менять без записи здесь.
